# What is Cloud Computing?

Cloud computing means using IT resources through the Internet.

These resources can include:

- Servers
- Storage
- Databases
- Applications
- Computing power

You do not need to buy and maintain all the physical hardware yourself.

## Simple Example

Suppose you want to create a website.

Traditional way:
- Buy a server
- Buy storage
- Maintain the server
- Pay for electricity
- Manage hardware

Cloud way:
- Take a server from AWS
- Use it when needed
- Pay for what you use

So:

Cloud = Use IT resources through the Internet + Pay for what you use

# IaaS, PaaS and SaaS

## 1. IaaS

IaaS = Infrastructure as a Service

You get basic infrastructure such as:

- Servers
- Storage
- Networking

You have more control.

### AWS Example

Amazon EC2

### Simple Example

You rent a virtual computer from AWS.

You decide:
- Which OS to use
- How much CPU
- How much RAM
- What software to install

---

## 2. PaaS

PaaS = Platform as a Service

AWS manages the underlying infrastructure.

You mainly focus on your application.

### AWS Example

Elastic Beanstalk

### Simple Example

You have a Java application.

You give your application to the platform.

The platform handles much of the infrastructure work.

---

## 3. SaaS

SaaS = Software as a Service

You directly use a complete application.

### Examples

- Gmail
- Dropbox
- Zoom

### Simple Example

You open Gmail and use email.

You don't manage the servers behind Gmail.
